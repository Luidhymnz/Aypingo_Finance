# 🐶 AYPINGO FINANCE

### Seu dinheiro organizado. Suas decisões mais inteligentes.

Um projeto de gestão financeira pessoal desenvolvido com **Python**, banco de dados e integração futura com **Inteligência Artificial**.

O AYPINGO FINANCE tem como objetivo ajudar pessoas a organizarem sua vida financeira, acompanharem receitas e despesas e obterem uma visão mais clara sobre seus hábitos de consumo.

## 🎯 Objetivo do projeto

Desenvolver uma aplicação de controle financeiro pessoal que permita registrar movimentações, acompanhar o orçamento e gerar informações úteis para auxiliar na tomada de decisões financeiras.

## ⚙️ Tecnologias

As tecnologias previstas para o desenvolvimento incluem:

- **Python** — lógica e desenvolvimento da aplicação.
- **SQL** — consultas e manipulação de dados.
- **Banco de dados** — armazenamento e gerenciamento das informações.
- **Inteligência Artificial** — integração futura para análises e recomendações financeiras.

## 🚀 Funcionalidades planejadas

- [ ] Cadastro de receitas.
- [ ] Cadastro de despesas.
- [ ] Categorização de movimentações financeiras.
- [ ] Consulta de saldo e movimentações.
- [ ] Relatórios financeiros.
- [ ] Visualização de gastos por categoria.
- [ ] Análise de hábitos financeiros.
- [ ] Integração com inteligência artificial.
- [ ] Assistente financeiro virtual.
